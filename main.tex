    \section*{Propuesta de solución}

    El código proporcionado para esta actividad consiste en utilizar el módulo \texttt{network} de MicroPython para configurar la Raspberry Pi Pico W comoun cliente y obtener todas las redes disponibles cercanas. Primero, se importa la librería \texttt{network} y se crea un objeto \texttt{wlan} en modo \texttt{STA\_IF} (Station Interface), que permite que el dispositivo actúe como un cliente WiFi. Se activa la interfaz con \texttt{wlan.active(True)} y se ejecuta el método \texttt{scan()}, que devuelve una lista de tuplas con información de las redes detectadas: SSID (nombre de la red), BSSID (dirección MAC del punto de acceso), canal, intensidad de señal (RSSI en dBm), modo de autenticación y si la red está oculta. Finalmente, se imprimen los resultados en la terminal.

    \section*{Propuesta de solución}

    La solución propuesta para esta actividad consiste en implementar un servidor web embebido en la Raspberry Pi Pico W que permita controlar un LED conectado al pin GPIO18 desde cualquier dispositivo con navegador web dentro de la misma red local. Para lograr esto, primero se configura la interfaz WiFi de la Pico W en modo estación (STA\_IF), lo que permite conectarla a una red existente mediante el módulo \texttt{network}. Una vez establecida la conexión y obtenida una dirección IP por DHCP, se crea un socket TCP enlazado al puerto 80 (HTTP estándar) que escucha peticiones entrantes. La interfaz web se construye mediante una función que genera código HTML con dos botones: uno para encender y otro para apagar el LED. Cuando el usuario presiona un botón desde su navegador, se envía una petición HTTP GET con un parámetro en la URL (\texttt{/?led1=on} o \texttt{/?led1=off}), el cual es analizado por el servidor para cambiar el estado del pin GPIO18 mediante \texttt{led1.value(1)} o \texttt{led1.value(0)}. El servidor responde con las cabeceras HTTP apropiadas y el contenido HTML actualizado, cerrando la conexión después de cada respuesta. Se incluye manejo de excepciones para garantizar que el servidor permanezca activo ante errores de comunicación.
